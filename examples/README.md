# Examples

Add runnable, credential-free examples here as features become implemented. Examples must not present roadmap APIs as available behavior.

## Hybrid example

The root `example_config.toml` is a credential-free mixed-mode mock configuration.
Run `cargo run -p oscar-cli -- run "Add JWT authentication" --out demo-run` from
the repository root with a new output directory. See `docs/hybrid.md` for real
local/remote configuration and limitations.

`hybrid-plan/PLAN.md` and `hybrid-plan/.plan/plan.json` are generated by the real
planner for the JWT example; no inference was used to create them.
